# application_access_hostname (Nested-Attribute)

This represents the Application Access hostname, which can be an IP Address or a Fully Qualified Domain Name (FQDN).




## Simple Attributes
- `application_access_hostname` (String) The hostname for the Application Access, which can be an IP Address or a Fully Qualified Domain Name (FQDN).
