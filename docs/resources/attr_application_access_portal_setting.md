# application_access_portal_setting (Nested-Attribute)

This represents the Application Access Portal Setting, which includes the Application Access Portal element and its service port.




## Simple Attributes
- `application_access_portal` (String) This represents an Application Access Portal. It contains settings for hostnames, policies, server credentials, and various portal configurations.
- `port` (Number) The Application Access Portal service port, which defines the port used for the Application Access Portal.
