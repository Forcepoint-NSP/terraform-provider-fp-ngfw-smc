# site_vpn_reference (Nested-Attribute)

This represents a reference to a VPN where the site can be found. The VPN is automatically referenced, and the site can be enabled or disabled in this VPN.




## Simple Attributes
- `enabled` (Boolean) Indicates whether the site is enabled in this VPN.
- `site_mode` (String) The mode of the site in the VPN. Can be 'Normal', 'Private', or 'Hub'.
- `vpn_id` (Number) The ID of the VPN where the site can be found.
